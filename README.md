# Расписание СФ УУНиТ

Android-приложение с виджетами для расписания [edu.str.uust.ru](https://edu.str.uust.ru).
Kotlin, Jetpack Compose, Glance.

## Сборка

```bash
./gradlew :app:assembleDebug     # отладочный APK
./gradlew :app:testDebugUnitTest # тесты парсера и логики дней
./gradlew :app:assembleRelease   # release с R8
```

`local.properties` должен указывать на Android SDK: `sdk.dir=путь/к/android-sdk`.
Требуется JDK 17, compileSdk 35, minSdk 26.

## Источник данных

У сайта нет документированного API, но есть внутренние endpoint'ы, которые
использует его собственный фронтенд. Они отдают HTML-фрагменты, которые
разбирает `ScheduleApi` через Jsoup.

| Endpoint | Метод | Параметры | Ответ |
|---|---|---|---|
| `php/getList.php` | GET | `faculty=<id>` | `<li>` со скрытым id и названием группы |
| `php/getShedule.php` | POST | `type=2`, `id`, `week` | шесть `div.day`, в каждом 8 слотов `li.lesson` |
| `php/getSheduleHeader.php` | POST | `type=2`, `id`, `week` | имя группы и границы недели |
| `php/getIdGroup.php` | POST | `group_name` | id группы или `0` |

Особенности разметки, на которые опирается парсер:

- `week` — **относительное** смещение недели: `-1`, `0`, `1`, …
- День всегда содержит ровно 8 слотов; пустой слот — это `li.lesson` без `div.name`.
- `div.type` содержит вложенный скрытый `div` с id занятия, поэтому берётся
  `ownText()`, а не `text()`.
- К аудитории сайт дописывает эмодзи-пиктограммы (`&#128421;`), они вычищаются.
- `type=1` — расписание преподавателя, `type=2` — группы.

Тесты парсера работают на HTML, снятом с живого сайта
(`app/src/test/resources/`), чтобы не разойтись с реальной разметкой.

## Архитектура

```
domain/     модели, DayLogic (какой день показывать)
data/
  remote/   ScheduleApi — HTTP + разбор HTML
  local/    Room: кеш дней, справочник групп, заметки
  prefs/    DataStore: тема, группа, настройки виджетов
  repo/     ScheduleRepository — склейка сети и кеша
ui/         Compose: расписание, предметы, настройки
widget/     четыре Glance-виджета
work/       WorkManager-синхронизация и напоминания
```

Виджеты никогда не ходят в сеть при отрисовке — только в кеш Room.
За наполнение кеша отвечает `SyncWorker`.

### Виджеты

| Виджет | Размер | Что делает |
|---|---|---|
| День | 4×2 | сегодня/завтра с автопереключением, стрелки листают дни |
| Следующая пара | 4×1 | идущая или ближайшая пара с обратным отсчётом |
| Неделя | 4×4 | вся неделя списком, стрелки листают недели |
| Заметки дня | 4×2 | заметки по предметам сегодняшнего дня |

Правило дня: с полуночи до `switchHour` (по умолчанию 17:00) — сегодня,
после — завтра. Воскресенья в расписании нет, оно всегда перескакивает на
понедельник. Налистанное стрелками смещение сбрасывается при смене суток.

### Оформление

Вся палитра выводится из одного оттенка (`NeonPalette.from`), поэтому ползунок
цвета перекрашивает приложение и виджеты связно, не ломая контраст: фон
остаётся тёмным, текст светлым.

Фон виджета рисуется в `Bitmap` (`WidgetBackground`), а не задаётся цветом или
shape-drawable. Так на API 26+ одновременно работают скруглённые углы, градиент,
свечение и произвольная прозрачность — `GlanceModifier.cornerRadius` требует
API 31, а shape-drawable не даёт градиента.

## Обновления

Приложение проверяет GitHub Releases при каждом запуске и показывает баннер,
если опубликована версия новее. По кнопке APK скачивается прямо в сессию
`PackageInstaller` и ставится **поверх установленной**: подпись та же, поэтому
настройки, выбранная группа и заметки сохраняются.

Выпуск новой версии:

```bash
./release.sh 1.1 "Что изменилось"
```

Скрипт поднимает `versionCode` и `versionName`, гоняет тесты, собирает
подписанный APK и публикует релиз с тегом `v1.1`.

Важное про это:

- **Репозиторий обязан быть публичным.** Приватный отдаёт ассеты только по
  токену, а токен, зашитый в APK, извлекается из него за минуту.
- **`versionCode` обязан расти.** Android не поставит поверх сборку с тем же
  или меньшим кодом, даже если `versionName` новее.
- **Дельта-обновлений здесь нет.** Патчить установленный APK умеет только
  Google Play; у Android нет публичного API для этого. Скачивается весь релиз,
  но он ~2.4 МБ и пишется потоком в сессию установки, без временного файла.
- Ключ подписи (`release.keystore`) и пароли (`keystore.properties`) лежат вне
  git. **Если потерять ключ, обновлять установленное приложение станет нечем** —
  только удалять и ставить заново, теряя данные.

## Известные ограничения

- Поддерживается одна активная группа; у отдельного виджета можно переопределить
  группу через `WidgetConfig.groupIdOverride`, но UI для этого пока нет.
- Расписание преподавателей и аудиторий сайт отдаёт, приложение их не показывает.
- Напоминания используют неточные будильники (`AlarmManager.set`), поэтому могут
  сдвигаться на несколько минут в Doze-режиме.
